# Archived research branches

These directories preserve the complete contents and Git histories of the repositories
that preceded the unified CervNet research workspace.

- `cervical-dataset/` — broad historical experimentation
- `curvature/` — five-class curvature work
- `quantitative/` — quantitative, regression, LightGBM, and SAINT work
- `vit-fracture-prototype/` — early fracture-classification prototype

The directories are intentionally kept close to their original state. They may contain
hard-coded paths, stale dependencies, IDE metadata, and notebook outputs. Use them for
provenance and migration—not as supported entry points.
